# Local installation

Follow the packaged [installation guide](../plugins/buyercaddy/INSTALL.md). Both portable and local compatibility configurations use the same OAuth gateway. The old direct `BUYERCADDY_API_KEY` environment setup is no longer the default package.

Use the source ZIP for repository-marketplace installation. Building does not change personal host settings. A local installation test is not evidence of a ChatGPT web connection or public publication.
